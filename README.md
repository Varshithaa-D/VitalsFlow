VitalsFlow: AI-Driven Healthcare Triage & Clinical ScribeVitalsFlow is a full-stack healthcare intelligence platform designed to optimize patient intake and automate clinical documentation. The system uses machine learning to prioritize patients based on medical urgency and Generative AI to assist doctors during consultations.  🛠️ Core Functionality1. Smart Triage System (Priority-Based)This module ensures that the most "at-risk" patients receive immediate attention.  Real-Time Vital Collection: Captures critical patient data including Systolic/Diastolic BP, Heart Rate, Respiratory Rate, Temperature, and SpO2.  Machine Learning Prioritization: Utilizes an XGBoost model (xgboost_real_triage.joblib) to analyze vitals and assign a triage level from 1 (Critical) to 5 (Non-Urgent).  Clinical Guardrails: Features built-in safety logic to ensure perfectly normal vitals are classified as non-urgent while abnormal patterns trigger high-priority alerts.  2. AI Clinical Scribe & Co-PilotThis module eliminates manual data entry by transforming doctor-patient conversations into structured medical records.  Multilingual Transcription: Uses Whisper-v3 to transcribe consultations, specifically optimized to handle English and regional languages like Kannada.  Automated SOAP Notes: Employs Llama 3.1 to parse transcripts and generate professional Subjective, Objective, Assessment, and Plan (SOAP) notes.  Proactive Decision Support: The AI analyzes symptoms in real-time to suggest standard-of-care diagnostic tests (e.g., CBC, ECG) and medications for the physician's review.  🧰 Tech StackFrontend: React.js, Vite, Tailwind CSS.  Backend: FastAPI (Python), Uvicorn.  Database: Supabase (PostgreSQL).  AI/ML: XGBoost, Groq API (Llama 3.1-8B & Whisper-v3-Large).
